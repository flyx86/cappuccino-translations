# cappuccino-translations

Language files are located in the `locales` folder.
The file name format must be `Cafe_lang.xml` where `lang` should be the file language (`fr`, `hu`, etc.)

## How to run the script

Requirement: You must have Node.js installed on your machine https://nodejs.org/fr/download

1. Install dependencies (you just have to do it once)

```sh
npm install
```

2. Execute the script

```sh
npm run sync
```
